# Origin and credit

TeamLoop was created by **Mark Salisbury with Codex** as a local system for coordinating his own authorized AI tools from one conversation.

[Claudex Loop by chaseai-yt](https://github.com/chaseai-yt/claudex-loop) inspired the starting workflow: have Claude and Codex challenge plans and code instead of relying on one model's confidence. TeamLoop was implemented separately, adding configurable roles, another frontier-lab transport, optional specialists, deterministic checks, context packets, failure records and lead adjudication.
