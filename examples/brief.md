# Export review exercise

This is a new public example, not one of the historical field-study prompts.

A small reporting app exports records to CSV. A download must preserve the user's filter, use deterministic column ordering, and handle untrusted cell text. The file is intended for spreadsheet users, not only a text editor.

The selected source file is deliberately incomplete. A reviewer should distinguish visible defects from assumptions and name a focused test that would settle an uncertainty. No browser or test execution has occurred just because a reviewer described one.
