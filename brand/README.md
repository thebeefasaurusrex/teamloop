# TeamLoop brand kit v1.0

Open index.html for the visual guide. Its core logo, fonts and instructions are embedded; keep the whole folder together for the downloadable asset links. The copy-ready sections are at the end and in AI-HANDOFF.md. BRAND-GUIDE.md is the text reference.

Logo assets are in assets/, font files in fonts/, portable CSS in css/, and machine-readable roles in design-tokens.json. Use PNG for reliable placement in ordinary design tools. SVG containers include a raster symbol and are not fully vector masters.

Hard shadow is the selected light treatment. Do not change the green or swap back to the earlier hunter-green ink. See the guide for exact values and limits.

This package is a digital-use brand kit, not a publication action. Supporting choices are labeled separately from the locked identity. Font licenses are included. Public artwork reuse licensing is not decided by this package.
